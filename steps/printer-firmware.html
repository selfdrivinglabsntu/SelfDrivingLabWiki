Step 02

3D Printer Firmware

Compile and flash custom Marlin firmware so the printer homes to Z-max instead of probing the bed.

In progress

On this page

    Compiling custom Marlin firmware is essential for our liquid handling system, as the stock Ender 3 S1 printers are hardcoded to use the BL Touch sensor to probe the print bed to define Z-min.

    Since we have customized our 3D printer to perform Z-max homing due to design constraints of the customized 3D bed plates, the firmware's directional and endstop settings need to be edited.

    Settings changed

    • Z homing direction
    • Endstop pin assignment
    • Software travel limits
    • Z bump when homing
    • Other settings to ensure a smooth compilation of the Marlin firmware

    The firmware is a .bin file in the Firmware folder of the repository. This contains the machine-readable code that the Ender 3 S1 understands.

    0. Flashing firmware on your Ender 3 S1 with STM32F4 chip

    If you have not already done so, download the repository. To flash the firmware onto your printer's SD card, you will need the Firmware folder of the repository.

    0.1. Formatting the SD card

    • Set the file system to FAT32.
    • Set the allocation unit size to 4096.
    • The 8 GB SD card that came with the printer is the most reliable, but anything under 32 GB should work.

    0.2. Copy the firmware folder to your SD card

    Copy the contents of the Firmware folder into the root of your formatted SD card.

    • private, DWIN_SET, TJC_SET and firmware.zlib are for updating the printer's display.
    • The STM32F4_UPDATE folder contains your custom firmware file, firmware-2ndApril2_4.bin.

    0.3. Flashing from the SD card

    1. Turn off your printer and wait 20 seconds to power-cycle it.
    2. While the printer is off, insert the SD card into the slot.
    3. Turn the printer on. You will briefly see the Creality loading screen while the board updates.
    4. Once you see the main menu, the code has been flashed successfully. The main menu is for visual aid only; it is not functional.
    5. Turn the power off again for 20 seconds, remove the SD card, and turn the printer back on to start using it.

    Important: Do not insert the SD card while the printer is turning on — it can cause the bootloader to hang. Always make sure the printer is off before inserting the SD card.

    0.4. Troubleshooting

    Flashing custom firmware on an Ender 3 S1 can sometimes be tricky. Here are some specific requirements and common issues to be aware of.

    STM32F4_UPDATE folder

    If you are only updating the mainboard and not the display, you can technically flash just the .bin file. However, in our experience it is much more reliable to place the firmware in a folder named STM32F4_UPDATE before flashing. The bootloader of the Ender 3 S1 with the STM32F4 chip often only looks for firmware in a folder named exactly STM32F4_UPDATE (the name is case sensitive).

    Firmware file naming

    The bootloader can be picky about the filename. The printer will often ignore a .bin file with the exact same name as the last one it flashed. Rename your file to something simple and unique, like firmware123.bin or f1.bin, before flashing again.

    Display stuck on the splash screen, loading page or blank

    If the display is stuck on the loading page or shows a blank screen for more than 2 minutes, it could mean one of the following:

    1. The firmware flashed properly but the screen is not compatible. Check this by connecting the printer to your computer and operating it through Pronterface. If you send the M119 command and see z_max: open, the firmware flashed properly. You will have to update the screen separately.
    2. Bootloader hang.
      1. Power-cycle the printer for 1 minute and try flashing the firmware again.
      2. If that doesn't work, download the official Creality firmware and flash it. Sometimes the bootloader needs to be "primed" by official Creality firmware before it will accept a custom one.

    Firmware not flashing

    1. Ensure your chip is STM32F4 and not STM32F1. You can verify this by checking the chip version written on the mainboard.
    2. Make sure your SD card is formatted properly.

    1. Flashing firmware on any other printer

    1.1. Prerequisites

    Install the following:

    • Visual Studio Code
    • The PlatformIO extension:
      1. Open VS Code.
      2. Go to Extensions (Ctrl+Shift+X).
      3. Search for PlatformIO IDE.
      4. Install it.

    1.2. Download the Marlin source code

    Download the Marlin-2.1.2.7 source code and extract the folder.

    1.3. Get the example configuration files

    Many boards and printers already have tested configurations. Download the configuration files and locate the ones for your printer and firmware version.

    Copy Configuration.h and Configuration_adv.h from the example files into the Marlin folder of the source code, replacing the existing files.

    1.4. Editing the code

    Work in progress — detailed code changes coming later.

    Most of the customization happens in Marlin/Configuration.h and Marlin/Configuration_adv.h:

    1. Disable the BL Touch sensor
    2. Define the Z-max endstop switch
    3. Set the Z-max position to 250
    4. Set the Z-max homing direction
    5. Set the homing bump
    6. Other changes

    Note: You might not need to make the PID control changes for your compilation. But for us, the firmware would not compile without them.

    1.5. Compiling the firmware

    1. Open platformio.ini.
    2. Locate default_envs = mega2560 and change it to your board's environment.

    1.6. The correct SD card

    Not all printers use a standard SD card for flashing firmware. You might need to use a microSD card and format it accordingly.

    For example, we also modified an Ender 3 V2 Neo, whose firmware was flashed from a microSD card by simply placing the .bin file in the root folder.

    1.7. Flashing the firmware

    Follow 0.3. Flashing from the SD card.

    2. Testing the firmware upload

    2.1. Check the Z-max limit switch

    Open Pronterface or the GUI and send the M119 command. You should see z_max listed instead of the z_min switch.

    2.2. Home the Z-axis

    Home the Z-axis from Pronterface or the GUI. If the gantry moves upwards and stops when the Z-limit switch is triggered (you can mount the switch, or simply click it by hand to test before mounting), you have successfully flashed the firmware.

    You can undo this anytime.
